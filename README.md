\# Byte Bot de Chamados 🤖



Bot do Microsoft Teams para abertura de chamados no GLPI.



\## 📋 Funcionalidades



\- ✅ Abertura de chamados de manutenção

\- ✅ Cadastro de novos colaboradores (restrito)

\- ✅ Validação de usuário por email (GLPI)

\- ✅ Validação de grupos para acesso restrito

\- ✅ Campos condicionais nos formulários

\- ✅ Múltipla escolha

\- ✅ Tratamento de erros



\## 🚀 Tecnologias



\- Python 3.x

\- FastAPI

\- Bot Framework SDK

\- GLPI API

\- Microsoft Teams
